# Regional map data

`countries.json` contains simplified 1:110m country boundaries and label coordinates
from [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) (public domain),
retrieved from [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson).
Capital names come from the [World Bank country API](https://api.worldbank.org/v2/country?format=json&per_page=400)
(CC BY 4.0). Retrieved 16 November 2026.

These are small-scale reference boundaries, not a statement on disputed sovereignty.
The map round uses a regional crop with five numbered countries and separate answers.
